# 智能报价生成器（360智能体平台主线）

## 重要前提
- 当前仅有 **「3个平台报价-网络攻防训练平台、人工智能实训教育平台、智能体实训平台报价100人.xlsx」** 中“智能体实训平台”sheet 的参考价（100人规模）。
- **无正式内部结算价、利润率、按并发/按课程等细分报价模型**。因此本 Skill 产出为 **参数化报价框架 + 占位符**，不是精确报价。

## 输入参数（追问补齐）
- `部署规模`：如 100人 / 200人 / 并发数
- `部署形态`：纯软件 / 软硬一体（含管理/计算/推理服务器） / 私有化 / 专属云
- `包含模块`：平台 licence + 课程包 + 认证 + 交付服务 + 硬件
- `项目类型`：实训室 / 产业学院 / 人才基地

## 处理流程
1. 读取资料库中的报价 sheet（智能体平台sheet），提取已知价格锚点（如100人基准）。
2. 按规模线性外推 **仅作示意**，明确标注“示意值，非商务报价”。
3. 套用下方模板生成 Markdown 表格。
4. 强制附加免责声明。

## 输出模板
```

|---|---|---|---|---|---|---|
| 1 | 平台软件授权 | 智能体实训平台基础模块 | 1套 | ［从sheet取］ | ［计算］ | 基准100人 |
```

## 约束
- 任何数字若资料库无依据，用 `［待补］` 或 `［从sheet取］` 占位，**不得编造具体金额**。
- 必须带“非最终价格”免责。
- 若用户要求精确报价，回复：“当前资料仅含100人基准参考价，精确报价需商务确认，我已生成框架供你填数。”
