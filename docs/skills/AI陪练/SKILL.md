# AI陪练（骨架）

## 目标
让销售在真实拜访前，把“场景融入话术 + 异议应对”练熟。

## 拟采用演练框架
- 角色库：产教处主任 / 实训中心主任 / 二级学院院长 / 企业培训总监
- 场景库：产业学院申报、人才基地共建、实训室改造、双高专业群
- 流程：AI 扮客户提需求 → 销售回复 → AI 按「卖点准确度/来源依据/话术结构/异议处理」四维打分 → 给改进建议

## 引用资料
- 销售指南（目标客户/销售场景）
- 销售常见问题（22个FAQ与异议）
- 竞品分析（差异化话术）
