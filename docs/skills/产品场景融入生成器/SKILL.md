# 产品场景融入生成器（360智能体平台主线）

## 适用场景
销售面对一所院校/基地，不知道如何把 360智能体应用开发实训平台 包装进对方的项目里。本 Skill 把零散产品资料组织成“可拿去谈”的方案包。

## 输入参数（向用户追问补齐）
- `客户类型`：职业技术学院 / 应用型本科 / 职教本科 / 产教融合实训基地 / 区域AI人才公共服务平台 / 企业培训中心
- `项目目标`：申报产教融合示范校、建产业学院、建人才基地、双高专业群、实训室改造、AI人才培养体系
- `预算区间`（可选）：用于报价参考
- `推的产品`（默认：360智能体应用开发实训平台）

## 处理流程
1. 从资料库检索该产品「一句话定义、核心功能、目标客户、典型场景」五要素。
2. 检索 `05 高校产教融合集成方案` / `06 人才基地产品方案` 中可复用口径（若库为空，明确说明“方案库待补充，以下为基于产品能力的通用建议”）。
3. 匹配客户类型与项目目标，生成融入路径。
4. 给出对接角色与面客话术（专业严谨，不夸大）。
5. 给出可交付材料清单（指向资料库文件名）。
