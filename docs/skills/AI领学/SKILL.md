# AI领学（骨架）

## 目标
让新销售在 1 周内搞懂产品，能独立应对基础客户提问。

## 拟采用学习路径（基于资料库）
1. 产品定义与定位（白皮书第1-2章）
2. 核心功能漫游（AI课堂/项目实训/智能体中心/模型实训）
3. 课程与认证体系（大模型与智能体课程介绍.xlsx / ADE认证）
4. 典型场景与方案（销售指南 / 解决方案）
5. 报价与交付常识（报价sheet / 招投标参数）
6. 常见异议应对（销售常见问题.docx）

## 交互方式（拟）
- 用户说“开始学习” → 推送第1模块摘要+资料链接
- 每模块结束 → 出 3 道选择题抽查
- 错题 → 回链对应资料

## 状态
🕓 P2 延后。当前 Agent 可直接用资料库回答学习类问题，正式领学逻辑待补。
