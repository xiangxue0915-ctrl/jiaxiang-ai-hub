# WorkBuddy 导入部署指南（你自己的账号）

> 目标：把本包变成销售可访问的网页链接。全程在你自己的 WorkBuddy 完成，AI助手不触碰你的账号。

## 步骤 1：建 Agent
1. 打开 WorkBuddy → 新建 Agent（智能体）。
2. 名称：`360产品销售赋能助手`
3. 角色设定：复制 `agent-prompt.md` 全文粘贴。
4. 风格：专业严谨。

## 步骤 2：建资料库并上传
1. 新建资料库，建议命名 `360销售赋能知识库`。
2. 上传原始 15 个文件（来自 `D:\30-产品管理\360产品\AI实验室平台（智能体实训）(1)`）。
3. 同时上传本包 `knowledge-base/` 下 4 个 README.md（作为索引与五要素摘要，提升检索）。
4. 可选上传 `360认证体系.pptx`、`360教育事业部渠道解决方案.pptx` 作参考。
5. 将资料库绑定到该 Agent。

## 步骤 3：挂 Skill
1. 在 Agent 配置里添加自定义 Skill。
2. 依次创建以下 Skill，内容分别复制本包 `skills/` 对应 `SKILL.md`：
   - 产品场景融入生成器
   - 智能报价生成器
   - AI领学（骨架）
   - AI陪练（骨架）

## 步骤 4：生成分享链接
1. 在 Agent 页面点“分享 / 生成对外链接”。
2. 设置访问权限（建议：凭链接访问，或限定邮箱/团队成员）。
3. 把链接发给销售。

## 步骤 5：验收
1. 用 `test-questions.md` 的 30 题跑一遍。
2. 重点看：报价是否带免责、缺失项是否拒答、来源是否标注。
3. 把答得不好的题反馈给 AI助手迭代提示词。

## 注意事项
- 原始文件含报价 sheet，但仅100人基准；正式报价仍须商务确认。
- 05/06 方案库当前为顶替内容，待你提供更针对性文档后替换。
- 不要在资料库放内部机密（本包已规避）。
- AI领学/AI陪练为骨架，当前靠 Agent 原生能力兜底。
