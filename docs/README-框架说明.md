## 1. 目标与定位

做一个**销售点开网页链接就能用**的 AI 工作台（对标 `zhixiang.fn.qq.com/partner` 的「智享AI助手」形态），让销售在**不知道产品、不知道卖点、不知道场景、不知道怎么融入产教融合/人才基地项目**时，能通过对谈快速拿到：

1. 产品是什么、长什么样（智能问答 / 文档获取）
2. 核心卖点与客户价值（智能问答）
3. 怎么把产品嵌进高校产教融合 / 人才基地项目（产品场景融入）
4. 一套可编辑的报价单框架（智能报价）
5. （延后）系统化学产品、练话术（AI领学 / AI陪练）

**交付形态**：你（印良华）在自己的 WorkBuddy 里建 Agent → 绑知识库 → 挂 Skill → 生成分享链接发给销售。本包提供所有可导入/可复制的成品。

## 4. 反幻觉与合规硬约束（写进 Agent 提示词）

1. **只基于知识库回答**，知识库没有的必须说“未在资料中找到”，禁止编造功能、价格、案例。
2. **报价只填模板参数**，标注“非最终价格，以合同为准”。
3. **输出带引用来源**（出自哪份资料），方便回溯。
4. **遇到模糊需求先追问**，不自行脑补客户情况。
5. **涉及价格/合同/交付周期等商务承诺**，提示销售“以书面确认为准”。
