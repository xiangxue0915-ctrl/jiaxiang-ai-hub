## 一、五要素（强制置顶）

- **产品名称**：360智能体应用开发实训平台（别名：AI实验室平台-智能体实训）
- **一句话定义**：面向智能体应用开发人才培养的综合实训平台，以“教、学、练、评、用、沉淀”为主线，提供课程、项目、模型、知识库、MCP工具、智能体构建与运营一体化能力。
- **核心功能**：AI课堂、项目实训、智能体中心（智能体广场/多智能体/ GUI智能应用/ MCP调用）、模型实训（体验/部署/训练/评测）、知识库与MCP工具、能力考核、后台运营管理。
- **目标客户**：高校人工智能/软件/计算机/网络安全专业；职业院校、产业学院、产教融合实训基地；企业培训与数字化部门；区域AI人才公共服务平台；培训机构与认证机构。
- **典型场景**：智能体应用开发课程实训、AI人才培养体系搭建、产业学院/人才基地实训底座、私有化AI实验室建设、AIGC+智能体师资培训。

---

## 二、产品架构（分层）

1. 基础能力支撑层：模型、数据、知识、工具、算力、文件存储
2. 智能体构建运行层：工作流、推理智能体、多智能体、GUI智能应用、知识库、MCP工具调用
3. 实训应用层：课程、项目、测评、智能体使用、成果展示
4. 运营管理层：用户组织、资源管理、课程管理、考核管理、智能体审核、运维监控

---

## 三、课程与认证

- 课程（来自《大模型与智能体课程介绍.xlsx》）：大模型方向2门、智能体方向6门（ADEA/ADEP/ADEE认证初级/中级/企业级综合实训、RAG、多智能体、MCP开发）、AI基础与通识2门，共10门。
- 认证：360 AI微认证、360 ADE智能体工程师认证（ADEA/ADEP/ADEE三级）、一考双证（360 ADE + 工信部NITE证书）。

---

## 四、部署与硬件

- 服务器：管理服务器、计算服务器、推理服务器A（35B约50并发）、推理服务器B（35B约100并发或70B约50并发）。
- 部署：支持私有化、专属云、混合部署；支持国产CPU/OS/数据库适配。
